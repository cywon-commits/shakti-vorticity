# shakti-vorticity

Code and manuscript for **"Boundary-controlled algebraic vorticity order in Shakti artificial spin ice"** (C. Won, in preparation).

Ground states of Shakti artificial spin ice correspond one-to-one to domino tilings: every unhappy vertex joins two perpendicular plaquettes into an L-tetromino. Each tetromino carries a vorticity `v = ±1` (circulation of its island moments). This repository contains the scripts used to derive and verify the results of the paper:

- the height formula `v = s(-1)^floor(h/4)` and the proofs of the coupling rule, flip invariance and total-vorticity conservation;
- exact Kasteleyn (dimer) calculations of `<v>`, of the phase field `Psi`, of the mean height, of two-point functions, and of defect pair weights;
- Monte Carlo sampling (domino shuffling, height-function Metropolis) for amplitudes, shape dependence, holes and structure factors;
- vertex-model integer programs for monomer strings, and dipolar Monte Carlo inside the ground-state manifold;
- the scripts that draw the figures of the manuscript.

## Layout

```
code/    all Python scripts (flat: many scripts import or read each other, keep them together)
paper/   REVTeX manuscript (main.tex, refs.bib, main.bbl, main.pdf) and figures (paper/figs)
```

## Requirements

Python 3.10+ with the packages in `requirements.txt`:

```
pip install -r requirements.txt
```

`pulp` ships the CBC solver used by the integer programs. LaTeX with REVTeX 4.2 is needed to build the manuscript.

## Running

Run scripts from inside `code/`. Several scripts write intermediate data into subfolders (`exact/`, `dip/`, `mono/`, `sq/`, `hole/`, `rect/`) and figures into `outputs/`; create them first:

```
cd code
mkdir -p exact dip mono sq hole rect outputs figcheck
```

Data files (`*.pkl`) are not included; they are regenerated by the scripts listed below. The figure scripts `pf_fig*.py` read these data files and write PDFs to `../paper/figs/`.

## Notes

- Conventions: chess cell `(i, j)` is black if `i + j` is even; black cells map to horizontal plaquettes. Thurston height increases by 1 along an uncrossed edge with a black cell on the left, normalised so that `h ≡ r(x, y) (mod 4)`.
- Exact Kasteleyn ratios in double precision are reliable up to Aztec order n ≈ 58; `exact_int.py` gives exact rationals (Bareiss elimination).
- The dipolar sums are truncated at 6 lattice constants (10 checked).

## Finite-temperature boundary of straight-edged samples (Sec. V E, Fig. 14)
- `edge_partial_ilp.py n` — open vertex model: pairing a set S of edge plaquettes costs exactly J|S|/2.
- `pf_edge.py`, `pf_test7.py n` — Pfaffian with monomers on the outer face; checked against brute-force subset sums (n = 5, 7).
- `edge_exact.py n x1 x2 ...` (x = J/T) — exact paired fraction and central |Psi| (low-rank Pfaffian seam updates).
- `edge_np.py n x` — <N_p> from edge probabilities (low-T law <N_p> = 2^(n+2) e^(-J/T)).
- `edge_mc.py` — independent Monte Carlo check; `pf_fig_edgeT.py` — Fig. 14.

## Dipolar replicas and Binder cumulant (Sec. VII, App. C)
- `dip_setup.py L point`, then `dip_binder.py L seed 3000 400 10` (four seeds per L = 24, 32, 48, 64); `dip_analyse.py` prints U(L,T), 2x with bootstrap errors.
